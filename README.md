# kpop-all-stars-bd
Este repositório contém as querys em SQL para criar uma base de dados para o K-Pop All Stars, um sistema de banco de dados que guarda informações relevantes sobre a indústria do K-Pop.

As querys desse repositório são referentes a implementação do banco de dados em Oracle XE, e a API que conecta com mesmo modelo de banco criado por mim, Gabriel Miranda e Giselle Porto é encontrada neste repositório: https://github.com/GabrielMiGC/projeto-kpop-BD-JS
Além disso, este repositório também contém a documentação do projeto.
